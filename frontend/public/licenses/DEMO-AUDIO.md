# Demo audio credits

`/demo/audio/presentation.mp3` is a 30-second music-only bed. It was synthesized for this demo in the character of the existing intro's A-minor organ pad and 120 BPM plucked arpeggio (`frontend/src/intro/intro.js`); it contains no narration. Rebuild the MP3 from `.audit/demo-audio/original-underscore.wav` with `python3 tools/build_presentation_audio.py`.

`/demo/audio/click.ogg` is `click_001.ogg` from **Interface Sounds** by Kenney (`Kenney.nl`), distributed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Source: [OpenGameArt Interface Sounds](https://opengameart.org/content/interface-sounds). Kenney notes that credit is appreciated but not required. The source pack's license is included at `/demo/audio/LICENSE-Kenney.txt`.
